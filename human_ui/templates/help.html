知識白板與 AI 共用知識庫 -- 核心概念說明

知識層與視覺層

BeakBroodNest 將資料分為兩個獨立層級。理解這個分層是使用白板時最重要的概念：

知識層 (Knowledge Layer)

  • 卡片 (Card) -- 最小知識單位
  • 關係 (Relation) -- 語意連結
  • 標籤 (Tag) -- 分類系統

永久性資料，跨白板共用，AI 可存取

視覺層 (Visual Layer)

  • 白板 (Canvas) -- 空間佈局
  • 卡片位置 (CanvasAtom) -- 座標與尺寸
  • 視覺連線 (CanvasConnection) -- 線段呈現

佈局資料，每張白板獨立

同一張卡片可以出現在多張白板上，各自有不同的位置和連線。 知識層記錄「事實」，視覺層記錄「如何呈現」。

實例：刪除連線與 BLOCKED 標章

當兩張卡片之間存在 blocks（阻塞）關係時， 被阻塞的卡片右上角會顯示 BLOCKED 標章。 這個標章反映的是知識層的狀態。

當你在白板上刪除一條連線時，系統的判斷流程：

1
你點擊連線，確認刪除
↓
2
視覺層：該白板上的連線立即移除
↓
3
系統檢查：底層的知識關係是否還被其他白板引用？
↓
無其他引用
知識關係一併刪除，BLOCKED 標章消失
仍有其他白板引用
知識關係保留，BLOCKED 標章仍顯示， 並以提示告知原因

這確保了你在一張白板上的操作不會意外破壞其他白板上仍在使用的知識關係。

三個破壞層級：移除卡片的選擇

在白板上「讓一張卡片消失」有三種不同層級的動作，破壞範圍與可救回性不同。 選錯了可能影響其他白板，甚至遺失資料。請依需求挑選。

1. 解除連結

右鍵 → 從白板移除
影響範圍
  • 當前白板：移除
  • 其他白板：不變
  • 卡片本體：保留
  • 交換包：不變
不可救回（但卡片本體仍在 DB）

2. 白板字紙簍

Delete 鍵 / 工具列「移除」
影響範圍
  • 當前白板：移除（進此白板字紙簍）
  • 其他白板：不變
  • 卡片本體：保留
  • 交換包：不變
可從此白板字紙簍救回（原位置）

3. 徹底刪除

右鍵 → 徹底刪除卡片
影響範圍
  • 當前白板：移除
  • 其他白板：全部移除
  • 卡片本體：從 DB 刪除
  • 交換包：連帶清除
  • 所有關係：連帶清除
不可救回（不會進任何字紙簍）

速查表

問題 1. 解除連結 2. 白板字紙簍 3. 徹底刪除
會影響其他白板上同一張卡片嗎？ 否 否 是（全部消失）

關於字紙簍是「白板私有」的： 每張白板各自有獨立字紙簍，互不干擾。在白板 A 用 Delete 移除的卡片，只會出現在白板 A 的字紙簍，不會跑到白板 B。這是為了避免與「交換包」（跨白板暫存區）混淆。

關於與交換包的差別： 字紙簍是「我刪掉了，但留個後悔藥」；交換包是「我主動寄存，準備搬到別的白板」。前者是負面動作的緩衝，後者是正面動作的中介。

白板快捷操作

  • 滾輪 -- 縮放
  • 右鍵拖曳 -- 平移畫布
  • 雙擊卡片內容 -- 進入編輯
  • 從錨點拖曳 -- 建立連線（卡片邊緣的小圓點）
  • 點擊連線 -- 刪除連線
  • Shift + 拖曳空白區 -- 框選多張卡片
  • Esc -- 取消目前操作 / 關閉面板
  • F（縮放列）-- Fit View，自動縮放到全覽
  • M（縮放列）-- 切換小地圖
  • Ctrl + Z / Ctrl + Shift + Z -- Undo / Redo（含心智圖、連線、變色）
  • Ctrl + A -- 全選白板上可見的卡片
  • Delete / Backspace -- 把選中的卡片送入白板字紙簍
  • Shift + 拖曳卡片邊緣到另一張卡片 -- 跳 modal 選 relation_type 建連線
  • 雙擊連線 -- 開啟連線編輯 modal（改 type / 顏色 / label / 刪除）

卡片編輯器（多卡片同時編輯）

雙擊卡片進入編輯器後，可同時開 N 張卡片並排編輯。所有熱鍵在卡片編輯器開啟時生效：

  • Ctrl + S -- 儲存目前游標所在的卡片（攔截瀏覽器「另存網頁」）
  • Ctrl + K, S -- 全部儲存並關閉編輯器（chord：先按 Ctrl+K 放開，再按 S；2.5 秒內未按下則取消）
  • Ctrl + K, Q -- 全部捨棄變更並關閉（含確認對話框，避免誤觸）
  • Esc -- 關閉編輯器（含 dirty 確認）
  • Ctrl + W / Ctrl + Q -- 瀏覽器層級保留，無法網頁攔截；但有未儲存變更時，瀏覽器會自跳「變更可能不會儲存」系統 dialog

採用 VS Code 風格的 chord 設計，跨 macOS / Windows / Linux 無快捷鍵衝突。

內聯結構化輸入（;; 連打）

在卡片編輯器內連打 ;; 可叫出結構化輸入選單：

  • ;; -- 觸發 schema 選單（任務、日期、人物、檔案、Item 等預設 schema）
  • 選定 schema 後填入欄位 -- 該段文字會變成「結構化 entry」（卡片右側欄會列出，可在白板上單獨拉連線）
  • 從 entry 右側錨點拖曳 -- 建立 entry-level 連線（細虛線）
  • 已收合的 ;; 物件可在 toolbar 點按重新展開／編輯

心智圖殼操作

右鍵任何卡片可選「建立心智圖（以此卡片為 root）」-- 該卡片變成 root，殼自動框住原位置。

節點熱鍵（焦點在心智圖節點時）

  • Tab -- 在當前節點下新增子節點（往深層）
  • Enter（非編輯）-- 新增同層 sibling（root 例外，會新增子節點）
  • Enter（編輯標題中）-- 只結束編輯，不新增同層（避免誤觸丟輸入）
  • Tab（編輯標題中）-- 結束編輯並新增子節點（連續往深層延伸）
  • Esc（編輯標題中）-- 取消編輯
  • Delete / Backspace -- 刪除節點及其整個子樹（送字紙簍可救回）
  • 方向鍵 -- 跨子樹同 depth 移動：
    • tree-right / tree-right-diag：↑↓ 同 depth 跨子樹（B1 ↑ 直達 A4）；← 父；→ 第一個子
    • tree-down：←→ 同 depth 跨子樹；↑ 父；↓ 第一個子
  • 可印字元 -- 立刻進入標題編輯模式並接收該字元
  • Ctrl + E / F2 -- 開啟詳細編輯器（完整 markdown / entries 編輯）

節點滑鼠操作

  • 單擊 -- 設為 active（吃熱鍵）
  • 雙擊 -- 編輯標題
  • 拖曳子節點 -- 同層排序 / 拖出殼變獨立卡（葉子）或變新心智圖（有子樹）/ 拖到別殼變該殼子樹
  • Ctrl + 拖曳 root 節點 -- root 必須 Ctrl 才啟動拖曳（避免誤拖整棵樹），純點擊只 select
  • Shift + 拖曳節點 -- 建 connection 線（含 root；節點 ↔ 節點 / 節點 ↔ 普通卡 / 節點 ↔ 文字框）
  • 右側 ▶/▼ -- 展開 / 摺疊子樹（per-session，重整不保留）

心智圖殼右鍵選單

  • 展開向右 / 展開向右-斜向 / 展開向下 -- 切換 layout（斜向：同層 sibling 階梯式右移）
  • 底色 -- 9 色色板選殼背景色
  • 框線 -- 實線 / 虛線 / 無框（保留底色）/ 全透明（殼隱形，僅見節點）
  • 解除殼 -- 殼消失，節點變獨立卡片留在白板上
  • 刪除殼+所有節點 -- 連節點一起送字紙簍

心智圖節點右鍵選單

  • 編輯標題 / 脫離殼
  • 外框 / 底色 -- 多選變色：先框選多張節點，再右鍵任一張，色板套用到全部選中（顯示「套用到選中 N 張」）；單張未選時只套該張
  • 重置外框與底色 -- 回到預設視覺
  • 刪除節點+子樹 -- 送字紙簍

連線操作補充

  • 連線變動入 undo stack -- 建線、刪線、改 type / 色都可 Ctrl+Z 反悔
  • 樹線（tree_parent）與連線並存 -- 樹線是灰色貝茲（無箭頭），canvas_connection 是彩色帶箭頭+label，視覺區分
  • 心智圖節點之間 connection -- 強制繞行 32px，避免同層 X 相同造成直線重疊
